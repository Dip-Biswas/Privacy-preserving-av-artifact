# Notices

## Crawl and provider detectors

The Selenium crawler (`crawl/crawler/`) and BeautifulSoup provider detectors
(`analysis/prevalence/`) are adapted from the open artifact originally
published by Shreyas Minocha under the MIT License (Copyright © 2025–2026).

This repository adds geographically matched GCP deployment scripts and extra
provider signatures used in a six-jurisdiction crawl.

## Responsible use

This artifact is for measurement and defensive evaluation. It does **not**
include exploit payloads or attack reproduction scripts. The evaluation
catalog is in `docs/ATTACKS.md`. Reviewer protocol is in `docs/guides/`.
The use restriction for that material is `docs/NOTICE-EVALUATION.md`.
